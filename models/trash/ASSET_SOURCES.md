# Demo Trash Assets

Current demo assets are local procedural meshes/textures created for the Gazebo
video scenario. They are not downloaded BlenderKit/Sketchfab models.

Reason: Blender is not installed in the current workspace environment, and no
external asset download was performed during this pass.

Files:

- `plastic_bag`: textured wavy OBJ generated by `scripts/generate_textured_trash_assets.py`;
- `paper_packaging`: textured low box OBJ generated by `scripts/generate_textured_trash_assets.py`;
- `aluminum_can`, `plastic_bottle`, `glass_bottle`, `cardboard_box`,
  `cigarette_butt`: local SDF/mesh demo props.

For final visual polish, replace these with manually downloaded `.glb/.dae/.obj`
assets from BlenderKit/Sketchfab/Poly Haven/etc. and record source URL, author,
license and attribution here.
